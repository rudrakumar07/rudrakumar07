### Featured Projects

#### [Rjs](https://github.com/rudrakumar07/Rjs) — High-Performance CRDT Library
A drop-in alternative to Yjs delivering the same functionality with **34.9x faster** sequential inserts and **6.4x less** memory usage. Built on block-wise RGA with packed numeric IDs and Yjs-compatible binary encoding. JavaScript, 18,100+ tests.

#### [Techie-Picasso](https://github.com/rudrakumar07/Techie-Picasso) — Real-Time Collaborative Whiteboard
A multiplayer drawing app with live cursors, comment pins, stickers, undo/redo, and infinite canvas. Built with React, Yjs CRDTs, WebSockets, PostgreSQL, Redis pub/sub, and Nginx load balancing across multiple server instances.

#### [The Daily Observer](https://github.com/rudrakumar07/deceiving-chatting-app) — Secure Hidden Chat Platform
A newspaper platform with a hidden real-time chat system behind a secret keyword. Features challenge-response auth, auto-lockdown against SQLi/XSS, file sharing, and admin dashboard. FastAPI + WebSockets + Redis.

#### [Ethernet Transfer](https://github.com/rudrakumar07/Ethernet-Transfer) — P2P File Transfer for Windows
A compact peer-to-peer file transfer app for direct Ethernet links. Single EXE, no Python required. Includes IP configuration and MIT licensed.
